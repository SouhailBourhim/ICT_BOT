# Docker Scripts

This directory contains Docker-related scripts and utilities:

## Scripts

- `build-docker.sh` - Build script for RAG System Docker container
- `start-docker.sh` - Quick start script for RAG System Docker deployment
- `docker-troubleshoot.sh` - Docker troubleshooting script for RAG System
- `quick-docker-check.sh` - Quick Docker check script
- `fix-docker-desktop.sh` - Docker Desktop fix script for macOS
- `setup-colima.sh` - Colima setup script (Docker alternative for macOS)

All scripts have executable permissions and can be run directly.
