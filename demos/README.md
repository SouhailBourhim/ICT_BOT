# Demonstration Files

This directory contains demonstration scripts and examples for the RAG system:

## Available Demos

- **analytics_monitoring.py** - Demonstrates analytics and performance monitoring capabilities
- **query_enhancer.py** - Shows query enhancement features including spell correction and term expansion
- **response_synthesis.py** - Demonstrates multi-source response synthesis and generation
- **ui_enhancements.py** - Interactive Streamlit demo of UI components and filtering features

## Running Demos

Each demo can be run independently:

```bash
# Analytics and monitoring demo
python demos/analytics_monitoring.py

# Query enhancement demo  
python demos/query_enhancer.py

# Response synthesis demo
python demos/response_synthesis.py

# UI enhancements demo (requires Streamlit)
streamlit run demos/ui_enhancements.py
```

## Purpose

These files showcase system capabilities and provide examples for developers and users to understand how to use various features of the RAG system.
