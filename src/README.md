# Source Code

This directory contains the main application source code organized into logical modules:

- `app.py` - Main application entry point
- `core/` - Core system components and base functionality
- `managers/` - Business logic managers and orchestration
- `processors/` - Data processing and transformation components
- `retrievers/` - Information retrieval and search components
- `models/` - Data models and interface definitions
- `ui/` - User interface components and layouts
- `utils/` - Utility functions and helper modules

## Structure

All Python modules follow a consistent structure with proper imports and interfaces defined in the respective `interfaces.py` files where applicable.
