# Utility Scripts

This directory contains general utility scripts:

## Scripts

- `health-check.sh` - Health check script for RAG System Docker deployment
- `start_enhanced_system.sh` - Enhanced RAG System startup script

## Description

- **System monitoring**: Health checks and status monitoring
- **System startup**: Enhanced system startup with environment configuration
- **Maintenance tools**: General maintenance and monitoring utilities

All scripts have executable permissions and can be run directly.
